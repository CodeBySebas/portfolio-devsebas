## 📄 Secciones

1. **Hero** — nombre, rol con typewriter effect y links sociales
2. **Sobre mí** — descripción, stats y card de contacto rápido
3. **Habilidades** — tecnologías agrupadas por categoría
4. **Proyectos** — tarjetas con links a GitHub y demo en vivo
5. **Certificaciones** — grid con todas las certificaciones
6. **Contacto** — formulario + links de contacto directo
7. **Footer** — logo, copyright y redes sociales

---

## ✨ Funcionalidades JavaScript

- **Typewriter effect** — escribe y borra roles en loop
- **Menú hamburger** — navegación responsive en móvil
- **Navbar blur** — borde verde al hacer scroll
- **Scroll reveal** — elementos aparecen con animación
